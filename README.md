## 🚀 사용 방법

1. IntelliJ IDEA에서 이 프로젝트를 엽니다.
2. 원하는 난이도 폴더에 Java 파일을 추가합니다.
3. 해당 파일의 `main` 메서드를 실행하고 문제의 입력값을 넣습니다.

`D1`~`D5`, `D8`, `역량테스트`, `CodeTree`에는 `package` 선언이 없는 Java 코드가 있습니다. IDE에서는 필요한 폴더를 소스 루트로 지정하고, 선택한 파일을 개별 실행합니다.

여러 파일에서 `Solution`처럼 같은 클래스명을 사용할 수 있으므로, 실행할 풀이를 기준으로 작업합니다. SWEA 제출 시에는 문제에서 요구하는 클래스명에 맞춥니다.

## 📝 기록 방식

- 기본 파일명은 `SWEA_문제번호.java`를 사용합니다.
- 다른 풀이와 개선 버전은 `_1`, `_2`, `_fastest` 등으로 구분합니다.
- 샘플·모의 SW 역량테스트 문제는 `역량테스트` 폴더에 모읍니다.
- `_Solving` 등 작성 중인 코드도 포함하며, 파일 수는 정답 인증 수를 의미하지 않습니다.
